# Sharing and contribution guidelines

This is a **personal GitHub repository**, hosted outside any employer-controlled environment, despite being private.

## Before committing

- Confirm you own the material and are authorised to store it externally.
- Do not upload company source code, documents, internal designs, proprietary templates, names of confidential projects, real tickets or internal meeting notes.
- Use mock data and independently developed examples, not lightly anonymised internal records.
- Check for API keys, passwords, certificates, tokens, customer information and personal data.
- Review source history as well as the latest files: deleting a secret in a later commit does not remove it from history.
- Review third-party package and asset licences.
- Keep access limited to named authorised accounts. Use least privilege.
- Obtain relevant approval before sharing material or accounts with workplace colleagues, including approval for access from corporate devices.

## Before inviting a collaborator

1. Confirm they are permitted to access a personal external repository.
2. Decide whether read-only access is sufficient.
3. Share only reviewed content.
4. Revoke access when no longer needed.

## Project readiness checklist

- [ ] Ownership and external-hosting permission verified
- [ ] No employer or third-party confidential information
- [ ] No secrets or sensitive personal data
- [ ] Synthetic example datasets only
- [ ] Dependencies and licences reviewed
- [ ] README, reproducible setup and limitations documented

## Important

Private repositories are not a substitute for employer-approved systems. Company security policy, contractual IP obligations and third-party licence conditions continue to apply.
