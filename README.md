# Work Showcase

A curated collection of independently developed, shareable prototypes, reference implementations, and reusable approaches to AI-enabled delivery, engineering productivity, automation, and portfolio management.

> **Private repository.** Access is by invitation only. Content must be reviewed for ownership, confidentiality and employer policy before sharing with colleagues.

## Project documentation standard

Each project should explain:
1. **Problem:** What the project solves.
2. **Approach:** Design decisions and architecture.
3. **Demonstration:** Screenshots or sample output using synthetic data.
4. **Running locally:** Dependencies and reproducible commands.
5. **Limitations:** Known gaps and next steps.
6. **Sharing status:** Whether the project has been reviewed for external sharing.

## Getting started

Clone with an authorised GitHub identity:

```bash
git clone git@github.com:anwarjkhan/work-showcase.git
cd work-showcase
```

You can also browse files through GitHub after being granted access.

## Safety and ownership

Do not copy employer-owned code, proprietary templates, internal documents, credentials, production datasets, internal architecture diagrams or confidential information into this repository. Replace any sensitive examples with independently authored material and synthetic data. See [sharing guidelines](docs/sharing-guidelines.md).
